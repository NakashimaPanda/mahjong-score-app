# 麻雀大会マネージャー

Version 1.2.0

4人打ち麻雀の成績を管理するアプリです。参加者の登録、対戦組み合わせの作成、半荘ごとの点数入力、成績表の表示とCSV書き出しまでを、このアプリだけで行えます。

アプリ本体はHTMLファイル1つ（`mahjong-tournament-manager.html`）でできています。サーバーやインストールは不要で、ブラウザでファイルを開くだけで使え、オフラインでも動作します。

## 主な機能

- メンバー登録（テキストファイルからの読み込みにも対応）
- 対戦組み合わせ（対戦表）の自動作成
- 半荘・卓ごとの点数入力と順位の自動判定
- 成績表（合計・順位つき）と対戦表・スケジュールの表示
- 結果のCSV書き出し
- 卓情報カードの印刷：対戦表をもとに、各参加者の回戦ごとの卓と開始時刻を記したカードをA4用紙（縦向き）に印刷できます。1枚に入れる人数は1人／2人／4人から選べます
- スケジュールの印刷：1日のスケジュールをA4用紙（縦向き）1枚に大きく印刷できます。会場への掲示用です
- 日本語／英語の表示切り替え（入力したメンバー名はそのまま表示されます）
- ダークモード／ライトモードの切り替え
- 未保存の変更がある画面（時間設定・卓設定・点数入力）から別の画面へ移動しようとすると、「保存して移動」「変更を破棄して移動」「キャンセル」の3択ダイアログを表示します（「変更を破棄して移動」を選ぶと、保存されていない変更は破棄されます）

## 使い方

### 1. ファイルを開く

`mahjong-tournament-manager.html` をブラウザで開きます。インターネット接続は必要ありません。

### 2. メンバーを登録する

「メンバー登録」画面で、参加者の名前を入力します。

- 名前を入れて Enter または Tab を押すと、次の名前欄へ移動します。最後の欄で Enter を押すと、新しい欄が追加されます。
- 名前は入力した時点で自動保存されます。保存操作は不要で、画面を移動しても入力内容は残ります。
- 対戦表を作成したあとでメンバーを変更すると、既存の対戦表・結果と合わなくなることがあります。その場合はメンバー登録画面を離れるときに確認メッセージが表示されます（対戦表は作り直してください）。
- テキストファイル（1人1行）から参加者を読み込むこともできます。「テキストから参加者を読み込む」ボタンからの読み込みは追加、メンバー登録画面へのドラッグ＆ドロップは現在の参加者をすべて置き換える新規登録になります。Shift_JIS のファイルにも対応しています。
- 対戦を行うには、4人以上の登録が必要です。

### 3. 時間を設定する

「時間設定」画面で、開催日と開始時刻、終わり方（半荘数／終了時刻）、1半荘の時間とインターバルを設定します。お昼休憩を入れる場合は、開始目安時刻と休憩時間も設定できます。

- 終わり方は「半荘数で決める」と「終了時刻で決める」のどちらかを選べます。選ばなかったほう（終了時刻／半荘数）は自動で計算して表示されます。
- 半荘と半荘の間にはインターバル（短い間隔）を入れられます。お昼休憩が入る区間では、お昼休憩がインターバルを兼ねます（重ねて加算はされません）。
- お昼休憩は、開始目安時刻に最も近い半荘の区切りから、設定した時間だけ入ります。決まった開始時刻は、開始目安時刻の欄に反映されます。
- お昼休憩の位置は、右側のスケジュール表示でお昼休憩のタイルをドラッグしても変更できます（置けるのは半荘と半荘の間だけです）。
- 半荘の時間は運営上の目安です。当日の進行が多少ずれてもかまいません。
- タイムラインの下の『スケジュールを印刷』から、そのまま掲示用に印刷できます

### 4. 卓のルールを設定する

「卓設定」画面で、最初の持ち点、返し点、ウマ（小・大）、「100点の扱い」を設定します。詳しくは後述の「計算方式」を見てください。

### 5. 組み合わせを作成する

メイン画面（成績表）で「組み合わせ作成」を押すと、半荘ごとの対戦表が作成されます。

組み合わせを作成したら、『卓情報カードを印刷』から1枚に入れる人数を選んで印刷できます。各参加者に切り取って渡せます。

組み合わせは機械的に決まります。同じメンバー・同じ半荘数からは、毎回同じ対戦表になります。そのうえで、次のような偏りが出ないように調整されます。

- できるだけ同じ人同士が繰り返し対戦しない
- 休み番が特定の人に偏らない（休み回数が少ない人から休み番になります）
- 同じ卓に3回連続で座らない（休み番を挟んだ場合は連続と数えません。1卓しかない場合など、避けられないときは例外です）

対戦表を作り直すと、入力済みの結果は消去されます。

### 6. 点数を入力する

「点数入力」画面で、半荘と卓を選び、4人の素点を入力します。

- 素点は「25300」でも「25.3」でも入力でき、どちらも 25300 として扱います。入力はキーボードでのみ行えます。
- 素点を入れて Enter または Tab を押すと、次の人の素点欄へカーソルが移動します。
- 場風は上から東・南・西・北で固定です。座る場風を変えるときは、名前をドラッグして移動したい場風の行へ重ねて離します。入力済みの素点・順位は、名前と一緒にその人について移動します。
- 3人分を入力すると、4人目は「持ち点×4 − 3人の合計」で自動入力されます。自動入力された値も手で直せます。
- 同点のときは、東に近い順に上位になります。順位は自動判定のあとで手で変更することもできます。
- 4人分の合計が持ち点×4にならないときは、画面下に通知が出ます（保存時にも確認が出ます）。

点数入力画面の開き方によって、最初の表示が変わります。

- 対戦表の行をクリックして開いた場合：その卓が選択され、入力済みの場合は保存済みのデータが反映されます。
- 上部の「点数入力」ボタン、またはメイン画面の「点数入力へ」ボタンから開いた場合：初期状態（先頭の半荘・先頭の卓、素点欄は空）で開きます。

なお、ボタンから初期状態で開いた画面でそのまま保存すると、その卓の保存済みデータは上書きされます。入力済みの卓を修正するときは、対戦表の行から開いてください。

### 7. 成績表を確認し、CSVで書き出す

メイン画面の成績表に、各メンバーの半荘ごとの最終点数、順位、素点が表示されます。

- セルの色は卓を表します（同じ半荘で同じ色＝同じ卓）。休み番はグレーで「休」と表示されます。
- 成績表のセルをクリックすると、その半荘・卓のメンバー詳細へ移動します。
- 「合計」または「順位」の見出しをクリックすると順位順（1位が上）に並び替わり、もう一度クリックすると元の登録順に戻ります。
- 「結果をCSVで書き出し」を押すと、結果をCSVファイルで保存できます。

## 計算方式

最終点数は、次の式で計算します。

```text
最終点数 ＝（素点 − 返し点）÷ 1000 ＋ ウマ ＋（1位のみオカ）
```

- ウマは、1位＋大、2位＋小、3位−小、4位−大です。例えばウマ 5・10 なら、小＝5、大＝10 と入力します。
- オカは1位に自動で付きます。
- 飛び・焼き鳥は扱いません（素点基準です）。

「100点の扱い」は、（素点 − 返し点）÷ 1000 で出る100点単位の端数の処理方法です。3つの方式から選べます。

| 方式 | 端数の処理 |
| --- | --- |
| 5捨6入 | 端数の絶対値が5以下なら捨て、6以上なら入れる |
| プラス切り捨てマイナス切り上げ | プラスは端数を捨て、マイナスは端数を上げて、いずれも0に近い整数にする |
| 素点そのまま | 端数を小数第1位までそのまま使う |

丸める方式（5捨6入／プラス切り捨てマイナス切り上げ）では、2位〜4位を先に丸め、1位がその誤差を受け取ります。そのため、どの計算方式でも4人の最終点数の合計は必ず0になります。

## データ保存について

入力内容は、この端末のブラウザ内（localStorage）に自動保存されます。別のブラウザや別の端末ではデータは共有されません。

ブラウザのサイトデータを消去するとデータも消えてしまうため、節目にCSVで書き出して保管してください。書き出しはCSVのみです。

メイン画面の「全データを削除」を押すと、メンバー・設定・対戦表・結果をすべて削除できます。この操作は取り消せません。

## 注意事項

- 4人打ち専用です。
- メンバーを保存し直すと、既存の対戦表や結果と合わなくなることがあります。その場合は対戦表を作り直してください。
- 時間設定を保存すると半荘数が変わることがあり、既存の対戦表と結果は消去されます。
